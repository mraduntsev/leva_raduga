# Лева Радуга

Лендинг в игровой стилистике: тьютор-персонаж для школьников — математика, информатика, видеоконтент, нейросети.

## Стек

- SvelteKit + Svelte 5 (runes)
- Tailwind CSS
- Web3Forms — приём заявок с формы
- Статическая сборка (`adapter-static`), деплой на GitHub Pages

## Фичи

- Тёмная/светлая тема
- Reveal-анимации на скролл, анимированные счётчики, скилл-бары
- Scrollspy-навигация
- Форма обратной связи без бэкенда

## Разработка

\```bash
npm install
npm run dev
\```

## Сборка

\```bash
npm run build
\```
